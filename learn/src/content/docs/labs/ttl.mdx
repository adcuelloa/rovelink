The device watches its own clock (`CONTROL_TTL_MS`, 500ms in the real protocol) since it last accepted a valid frame — not an expiry stamped on any individual message. If frames stop arriving — for any reason — the vehicle falls back to safe state on its own, without waiting for anyone to release a key. See [TTL & Watchdog](/safety/ttl-watchdog/) for the exact firmware mechanism this lab simulates.

<TtlTimeline locale="en" client:only="react" />

A heartbeat re-send keeps the clock reset while you're driving, comfortably faster than the TTL threshold — that gap is deliberate: an occasional dropped packet from ordinary network jitter must never look like a real disconnect.
