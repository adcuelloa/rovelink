Drive with **WASD or the arrow keys** (Space to stop, Q/E for the gripper, Z to arm/disarm — the real RoveLink keyboard mapping), the on-screen touch pad, or a real gamepad plugged in and moved. Everything below **CONTROLENGINE**, **CONTROLSENDER**, ownership, and the keyboard/gamepad handling is the actual, unmodified RoveLink code — only the network, relay, and firmware past that point are <span className="rl-badge-sim">SIMULATED</span>.

## What you're seeing

- **Input → Ownership**: only one source drives at a time — try holding a key, then touching the pad.
- **ControlSender**: the send-rhythm decision (immediate / rate / heartbeat) using the real `decideSend()`.
- **Firmware (sim)**: session, sequence, and disarmed-baseline checks, reproducing `applyControlFrame()` from the real firmware.
- **Differential mix**: the real `differentialMix()` from `@rovelink/protocol` — identical to what the firmware runs.

Try **Cut connection** while driving, then watch [Connection Safety](/labs/ttl/) for the focused version of what happens next.
