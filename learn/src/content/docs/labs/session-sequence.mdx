Two different rules, doing two different jobs:

- **Sequence number** orders frames _within_ one controller's connection — a stale or duplicate frame is dropped.
- **Control session** provides authority _across_ controller lifetimes — a delayed frame from a controller that has since reconnected can never come back and override the current one, no matter its sequence number.
