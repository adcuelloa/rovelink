RoveLink tracks two round-trip times, deliberately kept separate:

- **Relay RTT** — a ping answered at the Cloudflare edge. Proves the path to Cloudflare is fast. Never touches the robot.
- **Control RTT** — browser → relay → device → relay → browser, for one frame the firmware actually applied. The only number that proves the physical robot did something.
