## Following one command

The journey below traces a single realistic command: **DualSense R2 = 0.72, Left Stick X = -0.18**. Watch how it transforms at every stage:

1. **Physical input** — R2 analog value and stick position read by the Gamepad API
2. **Profile** — Racing profile maps R2 to forward throttle, Left Stick X to steering
3. **Ownership** — gamepad is the active source
4. **ControlEngine** — stores throttle 0.72, steering -0.18 as current desired state
5. **ControlSender** — decides "rate" (significant change, within budget)
6. **ControlFrame** — builds `{seq, sentAt, ttlMs, state}`
7. **Relay** — stamps `controlSessionId`, forwards to device
8. **Firmware** — validates session, seq, applies state
9. **Differential mix** — left = 0.54, right = 0.90
10. **ACK** — firmware confirms "I did that"
