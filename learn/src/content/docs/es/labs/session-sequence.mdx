Dos reglas distintas, con dos trabajos distintos:

- **Número de secuencia** ordena los frames _dentro_ de la conexión de un mismo control — un frame obsoleto o duplicado se descarta.
- **Sesión de control** da autoridad _a través_ de las vidas del controlador — un frame demorado de un control que desde entonces se reconectó nunca puede volver a pisar el actual, sin importar su número de secuencia.
