## Lo que vas a controlar

Este laboratorio ejecuta el pipeline real de control del lado del navegador de RoveLink — **InputOwnership**, **ControlEngine**, **ControlSender** — y simula la red, el relevo y el firmware después de ese límite. La mezcla diferencial es el `differentialMix()` real de `@rovelink/protocol`.

## Prueba esto

1. Presiona **Z** para armar el robot (observa el cambio de estado `armed`)
2. Mantén **W** para avanzar — observa cómo sube el valor de throttle
3. Presiona **A** o **D** para girar — mira el steering cambiar y las ruedas diferenciarse
4. Mantén el stick quieto y observa la decisión del sender alternar entre **rate** y **heartbeat**
5. Presiona **Espacio** para detener — nota el envío inmediato al frenar
6. Intenta una segunda fuente de entrada (panel táctil o gamepad) — observa la transferencia de propiedad
7. Intenta **Cortar conexión** mientras manejas — ve al robot detenerse solo

## Qué notar

- La propiedad se transfirió cuando usaste una segunda fuente de entrada
- El engine almacenó el estado más reciente — no se acumuló cola
- El sender decidió "immediate" en armar/desarmar/parar, "rate" en movimiento, "heartbeat" mientras se mantiene quieto
- El frame llevó seq, sentAt, ttlMs — el relevo marcó controlSessionId
- El firmware validó sesión y seq antes de aceptar
- La mezcla diferencial convirtió tu throttle/steering en velocidades de rueda izquierda/derecha
- El ACK confirmó que el robot aplicó tu comando
