Maneja con **WASD o las flechas** (Espacio para detener, Q/E para la pinza, Z para armar/desarmar — el mapeo real de teclado de RoveLink), el panel táctil en pantalla, o un control real conectado y en movimiento. Todo lo que está antes de **CONTROLENGINE**, **CONTROLSENDER**, la propiedad de entrada, y el manejo de teclado/control es el código real de RoveLink sin modificar — solo la red, el relevo y el firmware después de ese punto están <span className="rl-badge-sim">SIMULADOS</span>.

## Qué estás viendo

- **Entrada → Propiedad**: solo una fuente maneja a la vez — prueba mantener una tecla y luego tocar el panel.
- **ControlSender**: la decisión de ritmo de envío (immediate / rate / heartbeat) usando el `decideSend()` real.
- **Firmware (sim)**: verificaciones de sesión, secuencia y línea base desarmada, reproduciendo `applyControlFrame()` del firmware real.
- **Mezcla diferencial**: el `differentialMix()` real de `@rovelink/protocol` — idéntico a lo que corre el firmware.

Prueba **Cortar conexión** mientras manejas, y luego mira [Seguridad de conexión](/es/labs/ttl/) para la versión enfocada de lo que pasa después.
