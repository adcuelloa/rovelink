Presiona una tecla, toca la pantalla, o mueve un control de videojuegos, y en bastante menos de un segundo una rueda gira. Este es ese viaje, una etapa a la vez, sobre el mismo grafo que viste en [Arquitectura del sistema](/es/start/explore-the-system/) — usa **Anterior** / **Siguiente** (o **Reproducir**) abajo. El ejemplo de abajo sigue a R2 en el perfil de control Racing, pero el mismo viaje ocurre para cualquier entrada.
